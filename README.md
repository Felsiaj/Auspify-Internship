## Projects

### Task 1: Netflix Data Cleaning

Cleaned and preprocessed the Netflix dataset by handling missing values, duplicates, and inconsistent data.

### Task 3: Netflix Country Analysis

Analyzed country-wise Netflix content distribution and identified the top content-producing countries.

### Task 4: Trend Analysis by Release Year

Analyzed yearly Netflix content releases, compared Movies and TV Shows, and visualized release trends.

### Task 5: Netflix Rating & Genre Analysis

Analyzed content ratings and genres to identify the most common categories and patterns.
