# Task 4: Trend Analysis by Release Year

## Project Overview

This project analyzes Netflix content release trends using Python to understand how the distribution of movies and TV shows varies across release years.

## Objective

* Analyze Netflix titles by release year.
* Calculate yearly content counts.
* Identify peak release years and changes in release counts.
* Compare Movies and TV Shows.
* Visualize trends and derive business insights.

## Dataset

* Source: Cleaned Netflix dataset from Task 1.
* Total records: 8,790 titles.
* Total columns: 10.
* Analysis period: 1925–2021.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

1. Dataset inspection and release-year analysis.
2. Yearly Netflix title counts.
3. Identification of the highest and lowest release years.
4. Year-over-year changes in release counts.
5. Comparison of Movies and TV Shows by release year.
6. Top 10 release years by title count.

## Key Findings

* 2018 recorded the highest number of titles, with 1,146.
* 2017 and 2019 each had 1,030 titles.
* Movies account for more titles than TV Shows in the dataset.
* The dataset shows substantial growth in titles associated with recent release years.
* Lower counts in 2021 should be interpreted cautiously because dataset coverage may be incomplete.

## Visualizations

* Netflix Content Release Trends by Year.
* Netflix Movies vs TV Shows by Release Year.
* Top 10 Years with the Highest Netflix Content Releases.

## Output Files

* Netflix_Release_Year_Trend.png
* Movies_vs_TV_Shows_by_Release_Year.png
* Top_10_Release_Years.png
* Netflix_Yearly_Trend_Analysis.csv
* Netflix_Top_10_Release_Years.csv

## Conclusion

The analysis highlights the distribution of Netflix content across release years, identifies 2018 as the peak year in this dataset, and compares the release-year patterns of Movies and TV Shows.

These insights demonstrate how Python-based data analysis and visualization can help summarize content trends.
