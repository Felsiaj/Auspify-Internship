# Netflix Rating and Genre Analysis

## Project Overview
This project analyzes Netflix content ratings, genres, and differences
between Movies and TV Shows using Python.

## Objectives
- Analyze Netflix content rating categories.
- Identify the most common genres.
- Compare ratings across Movies and TV Shows.
- Create interactive visualizations using Plotly.
- Summarize key findings from the dataset.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Plotly
- Jupyter Notebook
- VS Code

## Key Findings
- TV-MA is the most common content rating, with 3,205 titles.
- International Movies is the most frequently listed genre, with 2,752 entries.
- Dramas and Comedies are also among the most common genres.
- Movies have more titles than TV Shows in this dataset.
- TV-Y and TV-Y7 ratings occur more frequently for TV Shows than Movies.

## Visualizations
- Content rating distribution.
- Top 10 Netflix genres.
- Rating comparison across Movies and TV Shows.
- Interactive genre and rating charts created with Plotly.

## Project Structure
- Dataset: Cleaned Netflix dataset.
- Notebook: Analysis code.
- Output: Charts and audience insights.
- Screenshots: Evidence of project execution.

## Conclusion
This analysis summarizes content rating and genre patterns in the
provided Netflix dataset using data analysis and visualization techniques.
